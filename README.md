# Diabetes Patient Analytics Dashboard | 100K+ Records

## How to Run
1. Download both `index.html` and the CSV dataset file.
2. Open `index.html` in your browser.
3. Upload the CSV file when prompted to load the dashboard.

An interactive healthcare analytics dashboard analysing hospital length of stay, 30-day readmission patterns, and healthcare utilisation among diabetic patients using 100,000+ patient records.

## Data Pipeline
1. **Data Source:** Diabetic patient dataset sourced from Kaggle (100K+ records).
2. **Data Cleaning:** Cleaned, structured, and transformed raw data using Microsoft Excel.
3. **Data Architecture:** Maintained data separately in CSV format, allowing the HTML dashboard to fetch data locally without embedding large datasets into the source code.
4. **Development:** Built an interactive HTML dashboard using Claude AI.
5. **Dynamic Updates:** Dashboard reads directly from the CSV file, allowing dataset updates without modifying the HTML code.
